# DIP Mastery — Digital Image Processing Interactive Mock Exam & Scoreboard

> **Course:** CCS4505 — Digital Image Processing  
> **Institution:** College of Computing & Information Technology, Arab Academy for Science, Technology & Maritime Transport (AASTMT)  
> **Source Exam:** `Week 04 - Sample practice questions (TF, MCQ, and ESSAY) - 1.pdf`  
> **Lectures Covered:** Weeks 01, 02, and 03 (Digital Image Enhancement, Fundamentals, Relationships, Sampling & Quantization)

---

## 🚀 Features

1. **Student Session & Identity Tracking:**
   - Welcome prompt for student name & academic ID.
   - Saves personal progress and test history across sessions.

2. **Full Mock Examination Simulation (76 Points Total):**
   - **Part I: 30 True/False Questions** (1 pt each).
   - **Part II: 16 Multiple Choice Questions** (1 pt each).
   - **Part III: 6 Essay & Problem Solving Questions** (30 pts total).
   - Timed examination countdown (45 minutes) with visual alerts.

3. **Practice & Study Mode (Instant Feedback):**
   - Immediate answer evaluation upon selection.
   - Full pedagogical explanations.
   - **Exact lecture citations:** Specifies the exact Lecture (Week 01, 02, 03), Slide Number, Slide Title, and verbatim quote directly from course slides.

4. **Live Class Scoreboard & Leaderboard:**
   - Real-time ranking with medal badges (🥇 #1, 🥈 #2, 🥉 #3).
   - Tracks total score, percentage, elapsed time, and section breakdown.
   - Filter by All Attempts, Simulation Mode, and student name search.

5. **Self-Scoring Rubric & Model Answers:**
   - Official criteria breakdown for every essay question.
   - Step-by-step mathematical calculations (e.g. 256×256 true-color image size calculation in bits, bytes, and KB).
   - Neighborhood diagrams ($N_4, N_D, N_8$) and comparison analyses (Enhancement vs Restoration, Set vs Logical operations, Indexed vs True Color).

6. **Official Lecture Answer Key & PDF Export:**
   - Single-page cheat-sheet view of all 52 questions with lecture citations.
   - Print-optimized CSS for generating offline study guides.
